# Owner Property Management PWA — v1.4

Закрытая PWA-система управления эксплуатацией объектов недвижимости для владельца, администраторов, сотрудников и арендаторов.

## Что нового в v1.4

Переработаны разделы **«Арендаторы»** и **«Сотрудники / Админ-панель»**.

### Арендаторы

- карточки арендаторов вместо сухой таблицы;
- поиск по компании, помещению, контакту и телефону;
- фильтр по объекту и состоянию обращений;
- сразу видно площадь, этаж, помещение, открытые и критические проблемы;
- отдельно показываются просроченные обращения;
- ответственный от собственника виден прямо на карточке;
- отображается последнее обращение арендатора и его статус;
- быстрые действия **«Открыть»**, **«+ Проблема»**, **«Редактировать»**;
- карточка арендатора стала полноценным рабочим центром: показатели, контакты, проблемы, история проверок при осмотрах;
- добавлено редактирование арендатора: объект, помещение, этаж, площадь, контакт, телефон, ответственный и рабочая заметка;
- никаких договоров, банковских или паспортных данных при этом не хранится.

### Сотрудники и админ-панель

- визуальные карточки сотрудников;
- поиск по имени, email, роли и объекту;
- фильтр активных, отключённых и всех сотрудников;
- видна текущая нагрузка сотрудника;
- количество открытых, просроченных и критических задач;
- количество проведённых осмотров за 30 дней;
- список объектов, к которым сотрудник имеет доступ;
- быстрые действия: **права и объекты**, **сбросить пароль**, **отключить / восстановить**;
- отключение сотрудника по-прежнему завершает его активные сессии, но не удаляет старые подписи и историю действий.

## Основные возможности

В систему входят кабинет владельца и админ-панель, объекты, арендаторы и помещения, проблемы и задачи, фото проблемы и фотоотчёты «до/после», дата/время и подпись исполнителя, подтверждение решения арендатором, еженедельные осмотры объектов, роли и права сотрудников, автоматическое назначение ответственных, оборудование и ТО, показатели, расходы, журнал безопасности и PWA.

Документы аренды, банковские данные, паспортные данные и произвольное файловое хранилище намеренно не включены.

## Быстрая установка на Ubuntu/Debian

```bash
git clone https://github.com/Deels2024/upravlenie.git
cd upravlenie
chmod +x install.sh
sudo ./install.sh
```

Установка v1.4 выполняется поэтапно:

1. восстанавливается проверенная production-база v1.1 из `release-v1.1/`;
2. базовый ZIP проверяется по SHA-256;
3. применяется UI-патч v1.2;
4. проверяется и применяется UI/UX-патч v1.3;
5. проверяется и применяется UI/UX + backend-патч v1.4;
6. при наличии Node проверяется синтаксис `public/app.js` и `server.js`;
7. при обновлении сохраняются `.env` и Caddy/HTTPS-настройки;
8. только после успешной проверки новая версия заменяет текущий код;
9. предыдущая версия остаётся в `app/property-owner-pwa.previous` как страховочная копия.

## Обновление установленного сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Данные приложения находятся в постоянных томах и при обновлении кода не удаляются.

## HTTPS

После направления домена на IP сервера:

```bash
cd app/property-owner-pwa
sudo ./enable-https.sh example.ru
```

## Безопасность

- база и фотографии не публикуются отдельными интернет-портами;
- роли и доступы проверяются на backend;
- арендатор видит только свои данные;
- demo-учётные записи блокируются в production;
- пароль владельца не хранится в GitHub;
- чувствительные API/PWA-данные не кэшируются как offline-контент;
- удаление объектов защищено ролями и проверкой связанных данных;
- архивирование сохраняет историю;
- отключение сотрудника прекращает активные сессии без удаления истории;
- обновления применяются только после проверки целостности и до замены рабочей версии.
