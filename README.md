# Owner Property Management PWA — v1.1

Закрытая PWA-система управления эксплуатацией объектов недвижимости.

## Что добавлено в v1.1

Раздел **«Объекты»** полностью переработан для повседневной работы владельца и администратора:

- современная карточочная сетка объектов;
- поиск по названию и адресу;
- фильтр по состоянию объекта;
- видимая заполняемость и свободная площадь;
- количество арендаторов и открытых проблем прямо на карточке;
- быстрый переход в карточку объекта;
- создание нового объекта;
- редактирование существующего объекта;
- назначение ответственного менеджера;
- рабочее примечание без хранения договоров и конфиденциальных документов;
- перенос объекта в архив с сохранением всей истории;
- восстановление объекта из архива;
- безвозвратное удаление только владельцем и только если у объекта нет связанных арендаторов, проблем, осмотров, оборудования или расходов;
- удобные формы и карточки для мобильной PWA.

В систему также входят: кабинет владельца, админ-панель, арендаторы, обращения и задачи, фото проблемы и фотоотчёты «до/после», дата/время и подпись исполнителя, подтверждение решения арендатором, еженедельные осмотры объектов, роли и права сотрудников, автоматическое назначение ответственных, оборудование и ТО, показатели, расходы, журнал безопасности, PWA, Docker/Caddy и резервное копирование.

Документы аренды, банковские данные и произвольное файловое хранилище в систему намеренно не включены.

## Быстрая установка на Ubuntu/Debian

```bash
git clone https://github.com/Deels2024/upravlenie.git
cd upravlenie
chmod +x install.sh
sudo ./install.sh
```

Установщик:

1. собирает production v1.1 из `release-v1.1/part-*.b64`;
2. проверяет ZIP по SHA-256;
3. распаковывает приложение в `app/property-owner-pwa`;
4. при обновлении сохраняет существующие `.env` и Caddy/HTTPS-настройки;
5. запускает встроенный production installer;
6. устанавливает Docker при необходимости;
7. запускает приложение и reverse proxy;
8. использует постоянные тома данных и резервные копии.

После первой установки терминал покажет адрес системы, логин владельца и сгенерированный пароль.

## Обновление установленного сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Код будет заменён новой версией. Production-секреты и доменная конфигурация сохраняются. Предыдущий исходный код временно остаётся в `app/property-owner-pwa.previous` как страховочная копия; данные приложения хранятся отдельно в постоянных томах.

## HTTPS

По IP проект может стартовать сразу. Для полноценного HTTPS сначала направьте домен на IP сервера, затем выполните:

```bash
cd app/property-owner-pwa
sudo ./enable-https.sh example.ru
```

## Безопасность

- база и фотографии не публикуются отдельными интернет-портами;
- роли и доступы проверяются на backend;
- арендатор видит только свои данные;
- demo-учётные записи блокируются в production;
- пароль владельца не хранится в GitHub;
- чувствительные PWA/API-данные не должны попадать в offline cache;
- удаление объекта защищено ролями и проверкой связанных данных;
- архивирование предпочтительнее удаления и сохраняет историю;
- production-релиз проверяется перед установкой по SHA-256.
