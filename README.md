# Owner Property Management PWA — v2.3

Закрытая личная PWA-система управления эксплуатацией собственных объектов недвижимости.

## v2.3 — объект как единый рабочий центр

В карточке каждого объекта появились вкладки:

- **Обзор** — Health Score, заполненность, арендаторы, открытые проблемы, ближайший осмотр, оборудование, просроченное ТО и последние расходы;
- **Арендаторы** — компании и помещения объекта с быстрым переходом в карточку арендатора;
- **Проблемы** — все обращения объекта, сроки, статусы и ответственные;
- **Осмотры** — история обходов и запуск нового осмотра;
- **Оборудование** — инженерные системы и сроки технического обслуживания;
- **Расходы** — последние месяцы, ₽/м² и доля ремонта.

Новый объект, арендатор, проблема, осмотр, оборудование или расход можно создать прямо из контекста выбранного здания. Объект подставляется в форму автоматически.

## Центр внимания

Главный экран теперь собирает в одном списке:

- просроченные и критические проблемы;
- обращения, ожидающие подтверждения арендатора;
- просроченные и ближайшие осмотры;
- просроченное и ближайшее ТО;
- аномальный рост электричества, воды или тепла;
- повторяющиеся проблемы.

Каждая строка ведёт сразу к нужной карточке или действию.

## Эксплуатационный календарь

Отдельный календарь объединяет:

- плановые осмотры;
- сроки технического обслуживания;
- сроки открытых проблем.

Есть месячный вид, счётчики просрочек и событий на ближайшие 7 дней, а также список ближайших работ. На мобильном календарь доступен с главного экрана и прокручивается без потери читаемости.

## Установка

```bash
git clone https://github.com/Deels2024/upravlenie.git
cd upravlenie
chmod +x install.sh
sudo ./install.sh
```

## Обновление сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Установщик:

1. проверяет consolidated baseline v2.0;
2. применяет проверенный premium UI v2.1;
3. подключает управление портфелем v2.2;
4. подключает рабочее пространство, Центр внимания и календарь v2.3;
5. проверяет синтаксис всех frontend/backend-модулей;
6. сохраняет SQLite-базу, фотографии, `.env` и Caddy/HTTPS-настройки;
7. заменяет рабочий код только после успешных проверок.

## Безопасность

- публичной регистрации нет;
- роли и права проверяются на backend;
- данные арендаторов изолированы;
- фотографии хранятся приватно;
- production требует 2FA владельца;
- административные события защищены HMAC hash-chain;
- старые объекты рекомендуется архивировать, чтобы не терять эксплуатационную историю;
- обновление прекращается до замены рабочей версии, если проверка сборки не пройдена.
