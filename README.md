# Owner Property Management PWA — v1.2

Закрытая PWA-система управления эксплуатацией объектов недвижимости для владельца, администраторов, сотрудников и арендаторов.

## Что нового в v1.2

Главный экран переработан в **операционный центр владельца**. Теперь с него быстрее выполняются ежедневные действия:

- крупные быстрые действия: **Объекты**, **Новая проблема**, **Провести осмотр**, **Арендаторы**;
- сразу видно количество открытых и просроченных проблем;
- отдельный блок **«Требует внимания»** с приоритетными обращениями;
- отдельный блок **«Последние осмотры»**;
- быстрый просмотр портфеля объектов;
- улучшена адаптация главного экрана для мобильной PWA;
- действия отображаются с учётом роли и реальных backend-разрешений пользователя.

## Управление объектами

Владелец и уполномоченный администратор могут:

- добавлять новые объекты;
- редактировать характеристики существующих;
- назначать ответственного менеджера;
- искать по названию и адресу;
- фильтровать по состоянию;
- видеть площадь, заполняемость, свободные м², арендаторов и открытые проблемы;
- архивировать объект без потери истории;
- восстанавливать объект из архива;
- безвозвратно удалять объект только при отсутствии связанных эксплуатационных данных.

Физическое удаление доступно только владельцу. Если существуют арендаторы, проблемы, осмотры, оборудование или расходы, система блокирует удаление и предлагает архив.

## Основные возможности

В систему входят кабинет владельца и админ-панель, арендаторы и помещения, проблемы и задачи, фото проблемы и фотоотчёты «до/после», дата/время и подпись исполнителя, подтверждение решения арендатором, еженедельные осмотры объектов, роли и права сотрудников, автоматическое назначение ответственных, оборудование и ТО, показатели, расходы, журнал безопасности и PWA.

Документы аренды, банковские данные, паспортные данные и произвольное файловое хранилище намеренно не включены.

## Быстрая установка на Ubuntu/Debian

```bash
git clone https://github.com/Deels2024/upravlenie.git
cd upravlenie
chmod +x install.sh
sudo ./install.sh
```

Установка v1.2 построена безопасно:

1. восстанавливается проверенная production-база v1.1 из `release-v1.1/`;
2. базовый ZIP проверяется по SHA-256;
3. применяется прозрачный Git-патч `patches/v1.2-ui.patch` только к интерфейсу;
4. при наличии Node выполняется синтаксическая проверка frontend;
5. при обновлении сохраняются `.env` и Caddy/HTTPS-настройки;
6. только после успешной проверки новая версия заменяет текущий код;
7. предыдущая версия остаётся в `app/property-owner-pwa.previous` как страховочная копия.

## Обновление установленного сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Данные приложения находятся в постоянных томах и при обновлении кода не удаляются.

## HTTPS

После направления домена на IP сервера:

```bash
cd app/property-owner-pwa
sudo ./enable-https.sh example.ru
```

## Безопасность

- база и фотографии не публикуются отдельными интернет-портами;
- роли и доступы проверяются на backend;
- арендатор видит только свои данные;
- demo-учётные записи блокируются в production;
- пароль владельца не хранится в GitHub;
- чувствительные API/PWA-данные не кэшируются как offline-контент;
- удаление объектов защищено ролями и проверкой связанных данных;
- архивирование сохраняет историю;
- UI v1.2 применяется поверх контрольной production-базы отдельным Git-патчем.
