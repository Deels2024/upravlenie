# Owner Property Management PWA — v1.3

Закрытая PWA-система управления эксплуатацией объектов недвижимости для владельца, администраторов, сотрудников и арендаторов.

## Что нового в v1.3

Разделы **«Проблемы»** и **«Осмотры»** переработаны под ежедневную эксплуатационную работу.

### Проблемы

- визуальные карточки вместо сухого списка;
- сразу видно объект, арендатора, категорию, приоритет и статус;
- фото **«До»** и **«После»** прямо в карточке;
- срок, ответственный, количество отчётов и стоимость;
- отдельная отметка просрочки;
- быстрые действия **«Открыть»**, **«Назначить»**, **«+ Фотоотчёт»**;
- поиск по проблеме, объекту, арендатору и ответственному;
- фильтры по статусу, приоритету, объекту и ответственному;
- быстрые выборки: критические, просроченные, без ответственного, ожидающие подтверждения арендатора;
- мобильная PWA-версия без горизонтальной перегрузки.

### Осмотры

- отдельные карточки плановых обходов;
- явно видно, что просрочено, что нужно сделать на этой неделе и что идёт по плану;
- кнопка **«Начать осмотр»** прямо из плана;
- история осмотров отображается карточками с фото фасада;
- видны инспектор, дата/время, состояние объекта, количество проверенных арендаторов и созданных проблем;
- быстрый переход к проблемам, созданным конкретным осмотром;
- фильтры истории по объекту и состоянию.

## Что было добавлено ранее

В v1.2 главный экран стал **операционным центром владельца**:

- быстрые действия **Объекты**, **Новая проблема**, **Провести осмотр**, **Арендаторы**;
- блок **«Требует внимания»**;
- последние осмотры;
- быстрый портфель объектов;
- улучшенная мобильная PWA.

В v1.1 было переработано управление объектами:

- создание и редактирование объектов;
- назначение ответственного менеджера;
- поиск и фильтрация;
- площадь, заполняемость, свободные м², арендаторы и проблемы;
- архивирование и восстановление;
- безопасное безвозвратное удаление только владельцем и только при отсутствии связанных данных.

## Основные возможности

В систему входят кабинет владельца и админ-панель, объекты, арендаторы и помещения, проблемы и задачи, фото проблемы и фотоотчёты «до/после», дата/время и подпись исполнителя, подтверждение решения арендатором, еженедельные осмотры объектов, роли и права сотрудников, автоматическое назначение ответственных, оборудование и ТО, показатели, расходы, журнал безопасности и PWA.

Документы аренды, банковские данные, паспортные данные и произвольное файловое хранилище намеренно не включены.

## Быстрая установка на Ubuntu/Debian

```bash
git clone https://github.com/Deels2024/upravlenie.git
cd upravlenie
chmod +x install.sh
sudo ./install.sh
```

Установка v1.3 построена поэтапно:

1. восстанавливается проверенная production-база v1.1 из `release-v1.1/`;
2. базовый ZIP проверяется по SHA-256;
3. применяется UI-патч v1.2;
4. проверяется SHA-256 сжатого UI-патча v1.3 и применяется v1.3;
5. при наличии Node выполняется синтаксическая проверка frontend;
6. при обновлении сохраняются `.env` и Caddy/HTTPS-настройки;
7. только после успешной проверки новая версия заменяет текущий код;
8. предыдущая версия остаётся в `app/property-owner-pwa.previous` как страховочная копия.

## Обновление установленного сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Данные приложения находятся в постоянных томах и при обновлении кода не удаляются.

## HTTPS

После направления домена на IP сервера:

```bash
cd app/property-owner-pwa
sudo ./enable-https.sh example.ru
```

## Безопасность

- база и фотографии не публикуются отдельными интернет-портами;
- роли и доступы проверяются на backend;
- арендатор видит только свои данные;
- demo-учётные записи блокируются в production;
- пароль владельца не хранится в GitHub;
- чувствительные API/PWA-данные не кэшируются как offline-контент;
- удаление объектов защищено ролями и проверкой связанных данных;
- архивирование сохраняет историю;
- обновления UI накладываются только после проверки целостности и до замены рабочей версии.
