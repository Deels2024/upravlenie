# Owner Property Management PWA — v2.4

Закрытая PWA-система управления собственными объектами недвижимости.

## v2.4 — надёжная работа на объекте

### Офлайн-осмотры

Если интернет пропал во время отправки готового осмотра, он сохраняется в локальной IndexedDB-очереди текущего браузера и автоматически отправляется после восстановления связи. На экране показывается состояние сети и количество неотправленных осмотров.

### Оптимизация фотографий

Перед отправкой эксплуатационные фотографии автоматически:

- уменьшаются максимум до 1920 px по длинной стороне;
- сжимаются до безопасного размера;
- перекодируются в JPEG;
- очищаются от EXIF-метаданных и GPS в отправляемой копии.

Серверные ограничения MIME и размера продолжают действовать отдельно.

### Контроль после ремонта

Для критических, высокоприоритетных и рискованных проблем после закрытия автоматически создаётся повторная проверка через 3, 7 или 14 дней. Контроль требует актуальную фотографию.

Если дефект повторился, система автоматически создаёт новую проблему высокого или критического приоритета и применяет действующие правила маршрутизации.

Контрольные проверки отображаются в Центре внимания и эксплуатационном календаре.

### Браузерные уведомления

Пользователь может явно включить локальные браузерные уведомления в окне уведомлений. Они работают, когда сайт или установленная PWA активны. Полноценный серверный Web Push остаётся отдельным будущим этапом, поскольку требует VAPID-ключей и отдельной политики доставки.

### GitHub Actions

Каждый push в `main` или `release/**` автоматически:

- собирает рабочую версию из baseline и overlay-модулей;
- проверяет базовые SHA-256;
- запускает syntax-check backend/frontend;
- запускает сервер;
- проверяет `/healthz` версии `2.4.0`.

## Уже входит в систему

- управление активными и архивными объектами;
- единая карточка объекта;
- арендаторы и помещения;
- проблемы с фото До / После;
- еженедельные осмотры;
- оборудование и ТО;
- показатели ресурсов и расходы;
- Health Score, Центр внимания и календарь;
- роли и доступы;
- TOTP-2FA владельца;
- HMAC audit-log;
- проверяемые резервные копии.

## Обновление сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Перед заменой рабочей версии установщик собирает v2.4 во временной директории и выполняет проверки. SQLite, фотографии, `.env`, 2FA и Caddy/HTTPS сохраняются.

## Важно

Офлайн-очередь хранится в браузерном профиле конкретного устройства. На общих компьютерах используйте отдельные учётные записи ОС и блокировку экрана.
