# Owner Property Management PWA — v2.6 Mobile PWA

Закрытая PWA-система управления собственными объектами недвижимости.

## v2.6 — полноценное мобильное приложение

PWA в проекте была уже раньше: manifest, service worker и базовая нижняя навигация существовали. В v2.6 этот слой доведён до нормального мобильного режима.

Что изменено:

- обновлён `manifest.webmanifest` для standalone-режима;
- добавлены mobile/Apple PWA meta-теги;
- новый service worker кэширует только оболочку приложения и статические ресурсы;
- `/api`, фотографии проблем и осмотров не кэшируются service worker;
- нижняя навигация владельца теперь содержит 4 основных раздела и кнопку **«Ещё»**;
- через «Ещё» доступны календарь, арендаторы, задачи, оборудование, показатели, расходы, админ-панель и безопасность согласно правам пользователя;
- добавлен install prompt на поддерживаемых Android/desktop-браузерах;
- на iPhone показывается инструкция «Поделиться → На экран Домой»;
- учтены `safe-area` iPhone;
- увеличены touch-targets, поля ввода и кнопки;
- модальные формы на телефоне работают как удобные нижние панели;
- длинные KPI-блоки и календарь адаптированы для небольших экранов;
- desktop-дизайн и бизнес-логика не меняются.

## v2.5 Production Start сохраняется

Одноразовая production-очистка v2.5 остаётся в цепочке обновления. Если она уже выполнялась, маркер `productionCleanStartAt` не позволит запустить её повторно. Если сервер ещё не успел её выполнить, v2.6 сохранит safety-backup, очистит тестовые эксплуатационные записи и оставит владельца с 2FA.

## Основные функции

- добавление и редактирование объектов;
- архивирование и восстановление объектов;
- безопасное удаление пустой архивной карточки владельцем;
- единая карточка объекта;
- арендаторы и помещения;
- проблемы с фото До / После;
- подтверждение результата арендатором;
- еженедельные осмотры;
- оборудование и ТО;
- показатели ресурсов и расходы;
- Health Score, Центр внимания и календарь;
- офлайн-очередь осмотров;
- оптимизация фотографий и удаление EXIF/GPS;
- контрольные проверки после серьёзных ремонтов;
- роли и доступы;
- TOTP-2FA владельца;
- HMAC audit-log;
- проверяемые резервные копии.

## Обновление сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Установщик создаёт staging-копию текущей рабочей версии, применяет v2.6, выполняет `npm run check` и syntax-check PWA/backend/frontend-модулей и только потом переключает рабочую директорию.

## GitHub Actions и деплой

- CI запускается на `main`, `release/**` и pull request в `main`;
- проверяет установщики, production-cleanup, PWA manifest, service worker и мобильный JS;
- deploy автоматически запускается после push в `main`;
- целевой сервер: `5.183.191.139`;
- healthcheck ожидает версию `2.6.0` на порту `8787`.

## Важно для установки PWA

Сам PWA-код готов, но полноценная установка service worker/PWA на обычном телефоне требует **HTTPS** (исключение — localhost). Если приложение открывается только как `http://5.183.191.139:8787`, веб-интерфейс работать будет, но нормальная установка PWA на iPhone/Android ограничена браузером. Для реального мобильного старта рекомендуется подключить домен с HTTPS через Caddy.
