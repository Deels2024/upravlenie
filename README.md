# Owner Property Management PWA — v1.5

Закрытая PWA-система управления эксплуатацией объектов недвижимости для владельца, администраторов, сотрудников и арендаторов.

## Что нового в v1.5

Завершён единый интерфейс разделов **«Оборудование / ТО / Показатели / Расходы»**.

### Оборудование и ТО

- карточки оборудования по объектам и инженерным системам;
- поиск и фильтры по объекту, системе и состоянию;
- сразу видно модель, расположение, последнее и следующее ТО;
- отдельные отметки **«ТО просрочено»** и **«ТО скоро»**;
- добавление нового оборудования;
- редактирование оборудования;
- фиксация выполненного ТО с датой, следующим сроком и комментарием;
- быстрые действия из карточки без лишних переходов.

### Показатели

- месячные показания электричества, воды и тепла;
- выбор объекта и периода;
- сравнение с предыдущим месяцем;
- автоматическая подсветка заметных отклонений и аномалий;
- быстрый ввод и обновление показаний;
- удобные карточки для мобильной PWA.

### Расходы

- эксплуатационные расходы по объекту и месяцу;
- категории: электричество, вода, тепло, уборка, охрана, ремонт и прочее;
- автоматический расчёт общей суммы;
- расчёт **₽/м²**;
- сравнение с предыдущим месяцем;
- визуальная структура расходов по категориям;
- ввод и редактирование расходов только пользователями с финансовым доступом.

## Основные возможности

В систему входят кабинет владельца и админ-панель, объекты, арендаторы и помещения, проблемы и задачи, фото проблемы и фотоотчёты «до/после», дата/время и подпись исполнителя, подтверждение решения арендатором, еженедельные осмотры объектов, роли и права сотрудников, автоматическое назначение ответственных, оборудование и ТО, показатели, расходы, журнал безопасности и PWA.

Документы аренды, банковские данные, паспортные данные и произвольное файловое хранилище намеренно не включены.

## Быстрая установка на Ubuntu/Debian

```bash
git clone https://github.com/Deels2024/upravlenie.git
cd upravlenie
chmod +x install.sh
sudo ./install.sh
```

Установка v1.5 выполняется поэтапно:

1. восстанавливается проверенная production-база v1.1;
2. базовый ZIP проверяется по SHA-256;
3. последовательно применяются проверенные обновления v1.2, v1.3, v1.4 и v1.5;
4. проверяется синтаксис frontend и backend;
5. при обновлении сохраняются `.env` и Caddy/HTTPS-настройки;
6. только после успешной проверки новая версия заменяет текущий код;
7. предыдущая версия остаётся в `app/property-owner-pwa.previous` как страховочная копия.

## Обновление установленного сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Данные приложения и фотографии находятся в постоянных томах и при обновлении кода не удаляются.

## HTTPS

После направления домена на IP сервера:

```bash
cd app/property-owner-pwa
sudo ./enable-https.sh example.ru
```

## Безопасность

- роли и доступы проверяются на backend;
- права на редактирование оборудования, показателей и расходов разделены;
- пользователь без `expenses_edit` не может менять финансовые расходы;
- арендатор видит только свои данные;
- база и фотографии не публикуются отдельными интернет-портами;
- пароль владельца не хранится в GitHub;
- обновления применяются только после проверки целостности.
