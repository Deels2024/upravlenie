# Owner Property Management PWA — v2.2

Закрытая личная PWA-система управления эксплуатацией собственных объектов недвижимости.

## v2.2 — удобное управление портфелем

Раздел «Объекты» теперь управляет фактическим составом портфеля:

- количество объектов считается автоматически по реальным карточкам;
- отдельные показатели: активные, архивные и общее число записей;
- вкладки «Активные» и «Архив»;
- быстрое добавление нового объекта;
- редактирование действующих объектов прямо из списка;
- перенос старых объектов в архив с сохранением истории;
- восстановление архивных объектов;
- окончательное удаление остаётся защищённым действием внутри карточки объекта и проверяется backend;
- поиск и фильтры работают в текущем режиме портфеля;
- интерфейс адаптирован для мобильной PWA.

Если объект добавлен, активный счётчик увеличивается автоматически. После архивирования он исключается из активного портфеля, но его история сохраняется.

## Что уже входит в систему

- Health Score объектов, площади и заполненность;
- арендаторы и помещения;
- проблемы, сроки, исполнители и фото До / После;
- еженедельные осмотры;
- сотрудники, роли и права;
- оборудование и ТО;
- показатели ресурсов и аномалии;
- эксплуатационные расходы;
- TOTP-2FA владельца;
- защищённый audit-log;
- проверяемые резервные копии;
- premium UI v2.1 и мобильная PWA.

Документы аренды, банковские и паспортные данные намеренно не хранятся.

## Установка

```bash
git clone https://github.com/Deels2024/upravlenie.git
cd upravlenie
chmod +x install.sh
sudo ./install.sh
```

## Обновление сервера

```bash
cd upravlenie
git pull
sudo ./install.sh
```

Установщик сохраняет существующую SQLite-базу, фотографии, `.env` и Caddy/HTTPS-настройки. Перед заменой рабочего кода проверяются baseline v2.0, premium UI v2.1 и overlay v2.2.

## Безопасность

- публичной регистрации нет;
- роли и права проверяются на backend;
- данные арендаторов изолированы;
- фотографии приватные;
- production требует 2FA владельца;
- административные события защищены hash-chain;
- старые объекты рекомендуется архивировать, чтобы сохранять эксплуатационную историю.
