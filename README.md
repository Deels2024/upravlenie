# Owner Property Management PWA

Закрытая PWA-система управления эксплуатацией собственных объектов недвижимости.

В production-релиз входят: кабинет владельца, админ-панель, объекты и арендаторы, обращения и задачи, фото проблемы и фотоотчёты «до/после», дата/время и подпись исполнителя, подтверждение решения арендатором, еженедельные осмотры объектов, роли и права сотрудников, автоматическое назначение ответственных, оборудование и ТО, показатели, расходы, журнал безопасности, PWA, Docker/Caddy и резервное копирование.

Документы аренды, банковские данные и произвольное файловое хранилище в систему намеренно не включены.

## Быстрая установка на Ubuntu/Debian

```bash
git clone https://github.com/Deels2024/upravlenie.git
cd upravlenie
chmod +x install.sh
sudo ./install.sh
```

Корневой установщик:

1. собирает полный production-пакет из `release/part-*.b64`;
2. проверяет его по SHA-256;
3. распаковывает приложение в `app/property-owner-pwa`;
4. запускает встроенный production installer;
5. устанавливает Docker при необходимости;
6. генерирует секреты и пароль владельца;
7. запускает приложение и reverse proxy;
8. настраивает постоянные тома данных и резервные копии.

После установки терминал покажет адрес системы, логин владельца и сгенерированный пароль.

## HTTPS

По IP проект может стартовать сразу. Для полноценного HTTPS сначала направьте домен на IP сервера, затем выполните внутри распакованного проекта:

```bash
cd app/property-owner-pwa
sudo ./enable-https.sh example.ru
```

## Безопасность

- база и фотографии не публикуются отдельными интернет-портами;
- роли и доступы проверяются на backend;
- арендатор видит только свои данные;
- demo-учётные записи блокируются в production;
- пароль владельца не хранится в GitHub;
- чувствительные PWA/API-данные не должны попадать в offline cache;
- production-релиз проверяется перед установкой по SHA-256.
