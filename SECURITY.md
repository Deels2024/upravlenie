# Security

Owner Property v3-clean — закрытое приложение без публичной регистрации. Production требует `OWNER_PASSWORD`; владелец создаёт остальных пользователей из админ-панели.

Секреты, SQLite DB, приватные фотографии и backups не коммитятся. Фото выдаются через авторизованный API. Для публичного доступа используйте HTTPS; после подключения домена включайте Secure cookies.

Перед каждым production deploy должны проходить `npm run check` и `npm test`.
